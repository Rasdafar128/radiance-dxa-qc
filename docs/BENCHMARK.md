# Замер на RTX 3090

Для актуального веб-интерфейса используйте `main`. Версия продукта остаётся 1.0; тег `v1.0.0` закрепляет исходную поставку модели, а её веса подходят к текущему коду.

```bash
git switch main
git pull --ff-only
```

Скачайте веса и запустите CUDA-вариант по [инструкции развёртывания](DEPLOYMENT.md). Данные организаторов переносите отдельно: их нет в Git. Для Windows эти команды выполняются в WSL2 с настроенным доступом Docker к NVIDIA GPU.

```bash
docker compose -f docker/compose.yaml -f docker/compose.cuda.yaml up -d --build --wait --wait-timeout 300
curl --fail http://127.0.0.1:8080/health
nvidia-smi
git rev-parse HEAD
```

Проверьте, что API использует CUDA. Подготовьте `data/benchmark.zip` с выбранными DICOM, без вложенных ZIP и посторонних файлов. Один и тот же пакет используйте для всех повторов. Остановите другие вычислительные задачи на GPU.

```bash
mkdir -p artifacts/rtx3090
for run in 1 2 3; do
  curl --fail --silent --show-error \
    -H 'Content-Type: application/zip' \
    --data-binary @data/benchmark.zip \
    --output "artifacts/rtx3090/run-${run}.csv" \
    --write-out '%{time_total}\n' \
    http://127.0.0.1:8080/batch > "artifacts/rtx3090/run-${run}-seconds.txt" || break
done
```

Это время HTTP-обработки всего пакета после загрузки модели, включая локальную передачу и чтение ZIP. Сохраните первый прогон отдельно: он может включать первоначальный прогрев CUDA. Не называйте его временем холодной загрузки модели. Сборку Docker тоже не включайте во время инференса.

Для презентации нужны число файлов и успешных результатов, время каждого прогона, максимум времени на исследование и характеристики компьютера. CSV содержит время на файл; времена успешных файлов одного исследования можно суммировать по `study_uid`. Строки без UID нужно учитывать отдельно. Ошибки нельзя исключать из общего числа файлов без пояснения.

Веб-сценарий проверьте отдельно на http://127.0.0.1:8000 или на развёрнутом сайте: его полное время дополнительно включает шлюз, создание превью и передачу в браузер.

Сохраните CSV и времена для дальнейшего разбора. В Git они не попадут: `artifacts/` исключён. Скрипт `src.utils.check` предназначен для полного исследовательского набора и локальных материалов аудита; для простого замера на новом компьютере достаточно команд выше.
