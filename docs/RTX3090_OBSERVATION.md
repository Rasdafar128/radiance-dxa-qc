# Обработка реальных DICOM на RTX 3090

23 сентября 2026 года выполнена одна загрузка ZIP с реальными DICOM через
https://sefixnep.ru. Сервер вернул HTTP 200 и CSV с результатом для каждого файла.

Стенд по сведениям владельца: NVIDIA RTX 3090 24 ГБ, Ryzen 7 5800X,
64 ГБ RAM, CUDA. Удалённая проверка аппаратной конфигурации не проводилась.

| Показатель | Результат |
|---|---:|
| Файлы / успешная обработка | 502 / 502 |
| Исследования по Study UID | 102 |
| Среднее серверное время файла | 0,133483 с |
| Медиана времени файла | 0,132118 с |
| Максимальное время файла | 0,565645 с |
| Сумма времени файлов | 67,008554 с |
| Максимальная сумма времени файлов одного исследования | 3,840382 с |
| Полный HTTP-запрос с передачей данных и превью | 87,729495 с |

Времена файлов взяты из CSV ответа сервера. Время исследования рассчитано
суммированием по Study UID, а не отдельным замером обработки исследования.
Сумма 67,01 с не является длительностью полного запроса. Это один прогон,
без оценки разброса повторных запусков или холодного старта.
Успешная обработка подтверждает работоспособность, а не точность классификации.

Размер исходного ZIP: 15 040 197 байт.
SHA-256: `2f6de9f8fb0705534894b270229a7f8455538a233eef28b7ed72caf28afd520b`.
Исходные DICOM, UID и полный ответ сервера в репозиторий не включены.
Локальные первичные материалы: `artifacts/rtx3090-upload/server-results.csv`,
`response.json`, `timing-summary.json`.
