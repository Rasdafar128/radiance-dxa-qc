# Руководство пользователя

Сервис оценивает укладку и полноту поля DXA. Поддержаны поясничный отдел позвоночника
и проксимальный отдел бедра. Для каждого изображения результат независим от имени
файла, порядка, дублей и состава пакета. Модель не оценивает остеопороз и не измеряет BMD.

## Через сайт

Откройте сайт по [инструкции](WEBSITE.md). Выберите DICOM или ZIP и нажмите
«Начать проверку». В результатах доступны фильтры, разбор выбранного снимка
и «Скачать CSV». Учебный пример содержит только вымышленные записи.
«Новая проверка» очищает текущий результат: сохраните CSV заранее, если он нужен.

## Обработка через API

1. Запустите контейнер по [инструкции](DEPLOYMENT.md).
2. Убедитесь, что `GET /health` возвращает `status: ok` и две модели:
   `dinov3-large`, `medimageinsight`.
3. Создайте ZIP с DICOM; допустимы вложенные папки. Отправьте **сам ZIP в теле**,
   без multipart/form-data:

```bash
curl --fail -X POST http://127.0.0.1:8080/batch \
  -H 'Content-Type: application/zip' --data-binary @studies.zip -o results.csv
```

4. Откройте CSV как UTF-8, разделитель — запятая. Поля с разделителями заключены
   в кавычки по стандарту CSV. Проверьте `processing_status` перед интерпретацией.

CSV формируется после обработки всего пакета; ожидание HTTP зависит от его размера.
Снимки хранятся во временном файле запроса, который закрывается и удаляется после ответа.
Инференс последовательный: один запрос модели за раз, один кадр на forward.
Для локального использования авторизация не требуется; порт опубликован только на localhost.

## Колонки CSV

| Поле | Содержимое |
|---|---|
| `path_to_study` | имя файла внутри ZIP или путь, переданный CLI |
| `study_uid` | исходный StudyInstanceUID, если прочитан |
| `image_uid` | исходный SOPInstanceUID, если прочитан |
| `anatomical_region` | одна из двух точных строк области ниже |
| `quality_class` | 0 — нарушение не обнаружено; 1 — найден хотя бы один тип |
| `quality_prob` | оценка нарушения [0;1]; не обязана пересекать 0,5 при классе 1 |
| `violation_type` | типы через `; `, пустое поле при отсутствии |
| `processing_status` | `Success` или `Failure` |
| `time_of_processing` | секунды обработки файла, без холодной загрузки модели |

| Область | Возможные типы |
|---|---|
| Поясничный отдел позвоночника | Некорректная укладка; Не выравнена ось позвоночника; Присутствуют посторонние предметы |
| Проксимальный отдел бедра | Некорректная укладка; Некорректная область интереса |

Списки точных строк определены в `src/config.py`.
Протез обрабатывается как обычное бедро: сам по себе не задаёт Failure или нарушение.
Неизвестные результаты при Failure остаются пустыми, не превращаются в класс 0.
Ошибки конкретных файлов записываются в журнал сервиса.

## Вход и ошибки

Поддерживаются однокадровые монохромные DICOM, MONOCHROME1/2, 1–16 хранимых бит,
не более 16 млн пикселей. Проверенные данные — несжатые DXA GE Lunar Prodigy Advance.
Декодеры JPEG-LS/JPEG2000 не включены; такие файлы могут получить Failure.
Цветные, многокадровые, постоянные по интенсивности и повреждённые изображения
получают Failure. Файлы не фильтруются по расширению: каждый элемент ZIP даёт строку.

| Ситуация | HTTP | Действие |
|---|---:|---|
| Валидный ZIP, в том числе с отдельными повреждёнными DICOM | 200 | читать статусы строк |
| Повреждённый/пустой ZIP, опасный путь, шифрование или превышение распакованного лимита | 400 | исправить архив |
| ZIP больше 256 MiB при загрузке | 413 | разбить пакет |
| Нет Content-Type `application/zip` или `application/octet-stream` | 415 | исправить заголовок |

Лимиты: 10 000 файлов, 512 MiB суммарно после распаковки, 32 MiB на файл.
Пути `..`, абсолютные пути и обратные слеши отклоняются; ZIP не распаковывается
в пользовательские пути файловой системы. Дубли сохраняются отдельными строками.

## Демо-сценарий

Подайте три предоставленных отладочных DICOM, затем тот же пакет с одним
повреждённым файлом. Ожидается 3 Success + 1 Failure; ответы исходных трёх файлов
сохраняются. Отладочные снимки проверяют интеграцию, а не качество модели.
Для демонстрации используйте локальные разрешённые данные; в репозитории их нет.

Известные ограничения качества и метрики — [карточка E5](../models/e5/README.md).
