Первые пять соответствуют обязательным слайдам 7–11 шаблона организаторов:
сохранены исходные сетка, размеры, расположение блоков, шрифты и оформление.
На слайде команды удалены три лишние карточки, две оставшиеся не перемещены
и не увеличены. Чиби размещены только на дополнительных слайдах 6–10.
Такое размещение соответствует разъяснению Антона Зеленского, переданному командой.

обязательных слайдов исходному шаблону и отображение всех десяти слайдов в PDF.

Переносы титула и имён исправлены, текст пятого слайда сокращён.

PDF экспортирован из той же версии PPTX. Проверка выполнена в LibreOffice;
отображение в настольном PowerPoint и Keynote отдельно не подтверждено.
