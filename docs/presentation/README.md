# Презентация Radiance

- [PDF для просмотра и показа](Radiance.pdf).

- [Сценарий выступления на 7–8 минут](SPEAKER_NOTES.md). Официальный лимит выступления не подтверждён.
- `fonts/`: Montserrat Regular и Bold с лицензией OFL. Установите шрифты перед редактированием PowerPoint; PDF уже содержит их.

Актуальная редакция от 23 сентября: 10 слайдов по шаблону организаторов, чиби участников, QR-коды на репозиторий и https://sefixnep.ru. Последовательность персонажей: Михаил Вершинин слева, Семён Родионов справа. Чиби созданы с помощью AI по предоставленным участниками фотографиям. Фоны и логотипы сохраняют права организаторов.

Старые замеры на Mac убраны. После запуска на RTX 3090 нужно добавить измеренные результаты в слайд 9. Развёртывание веб-приложения на указанном домене этими файлами не подтверждается.

Перед конкурсной отправкой остаётся добавить контакты участников и проверить регламент выступления. Достижения команды предоставлены участником. Метрики модели относятся к разработческой оценке, а не к закрытому тесту организаторов.

На слайде 8 показан разрешённый организаторами пример из конкурсных данных; [основание](../../context/sources/2026-09-18-answers.md), ответ 3. Исходные DICOM в репозиторий не входят.
