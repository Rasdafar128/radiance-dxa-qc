# Исследование и проверка качества

Это воспроизводимый журнал разработки, включая отрицательные результаты.
Он объясняет выбор Radiance (исследовательское обозначение E5) и границы качества, но не является независимым тестированием.

| Документ | Что содержит |
|---|---|
| [Финальный аудит](AUDIT.md) | проверка разделений, повторное обучение голов и пересчёт метрик |
| [Результаты аудита JSON](results/final_audit.json) | агрегаты и SHA256 входных OOF, без идентификаторов исследований |
| [Независимый пересчёт](results/validation_review.json) | исходные DICOM/Excel, срезы по фолдам и областям, precision/recall |
| [Проверка OOF по пикселям](results/validation_pixels.json) | 249 исходных кадров через модели внешних фолдов, без кэша признаков |
| [Эксперименты](EXPERIMENTS.md) | сравнение предобученных моделей и диагностика F1 |
| [Завершающий цикл](ML_CYCLE3.md) | дополнительные гипотезы, исправление E4, выбор финального E5 |
| [Обзор источников](RESEARCH.md) | модели, статьи, лицензии и кандидаты |
| [Сегментация анатомии](SEGMENTATION.md) | выбор SAM Large по трём отладочным примерам; ограничения без эталонных масок |

Исходные данные, OOF с идентификаторами, кэши признаков, снимки и промежуточные
чекпойнты находятся в локальных `data/` и `artifacts/`, исключённых из Git.
Сводные результаты ниже можно публиковать вместе с кодом. Финальные энкодеры
распространяются через GitHub Release; конфигурации — в [models/radiance](../models/radiance/README.md).

Контекст конкурса и решения по требованиям: [context](../context/README.md).
Воспроизведение обучения: [docs/TRAINING.md](../research/TRAINING.md).

Обозначения E0–E10 и пути опытов сохранены только для сопоставления
исторических артефактов. В рабочей поставке модель называется **Radiance**.
[Происхождение](results/radiance_provenance.json) связывает финальную модель
с исходным опытом; [воспроизведение обучения](TRAINING.md) описывает процедуру.
