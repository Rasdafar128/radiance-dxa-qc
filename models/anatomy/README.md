# Radiance Anatomy · экспериментальная сегментация

Необязательный режим сайта: пользователь задаёт рамку вокруг одной структуры,
**SAM ViT-L** строит бинарную маску. Это сегментация по подсказке пользователя,
без автоматического определения названий костей, позвонков или мест нарушения.

| Свойство | Значение |
|---|---|
| Предобученная модель | [Meta Segment Anything, ViT-L](https://github.com/facebookresearch/segment-anything) |
| Код инференса | `segment-anything==1.0`, PyTorch 2.8.0 |
| Веса | `sam-vit-large.pt`, 1 249 524 607 байт; SHA-256 и источники в `weights.json` |
| Лицензия компонента | [Apache 2.0](LICENSE) |
| Обучение на DXA | не выполнялось |
| Подсказка | рамка пользователя, нормированные координаты `[x0, y0, x1, y1]` |
| Вход | исходное PNG-превью DICOM, до 1024 px по стороне; настройки яркости сайта не учитываются |
| Выход | бинарный PNG 0/255 и цветной прозрачный слой в размере превью |

## Подключение

Из корня репозитория:

```bash
python3 -m src.utils.prepare_segmentation
python3 -m src.utils.prepare_segmentation --verify-only
```

Скрипт скачивает фиксированный checkpoint из открытого хранилища Meta и проверяет
размер и SHA-256. Копия весов прикреплена к [релизу 1.0](https://github.com/sefixnep/LCT26/releases/tag/v1.0.0)
как `sam-vit-large.pt`; её можно положить в этот каталог вручную и проверить второй командой.
Токен Hugging Face не нужен. Скачивание выполняется до сборки; инференс работает без сети.

Затем пересоберите API и веб-сервис по [инструкции сайта](../../docs/WEBSITE.md).
При отсутствии весов обычная проверка качества работает, инструменты сегментации
не предлагаются. Модель загружается при первом запросе и использует тот же CPU/GPU,
что Radiance; один общий lock не допускает одновременных вычислений двух задач.

SAM добавляет около 1,25 ГБ весов и расход памяти при вычислении маски. Совместный
CPU-контейнер прошёл отладочный сценарий с 7,75 GiB RAM; пик cgroup — 7,23 GiB.
Для запаса планируйте 12–16 ГБ RAM. Это не доказанный минимум для любых входов.
SAM в этой поставке проверен на Apple MPS и CPU Docker; совместный CUDA-инференс
с Radiance нужно отдельно проверить на целевом сервере.

## Проверка и ограничения

На трёх отладочных DXA визуально сравнены MedSAM ViT-B и SAM ViT-L с одинаковыми
рамками. SAM ViT-L давал меньше захватов фона на двух снимках бедра. Это ограниченная
проверка работоспособности и выбор прототипа, **не независимая оценка качества**.
Модель может пропускать часть структуры, особенно в местах перекрытия костей,
или захватывать соседние ткани. Пользователь должен проверить маску и изменить
рамку при необходимости. Dice/IoU не заявляются: эталонных масок нет.

Сегментация не меняет классификатор, пороги, CSV или опубликованный F1 Radiance.
Маска не является разметкой нарушения или автоматически рассчитанной областью
денситометрического измерения. Это не DICOM SEG; PNG повторяет геометрию превью,
которое может быть уменьшено относительно исходного файла.
